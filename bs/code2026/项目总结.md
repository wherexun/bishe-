# 校园小卖部商城系统 (Web端) | 毕业设计 2026.03 - 2026.05

本项目采用 Spring Boot + MyBatis + MySQL + Vue 实现校园小卖部商城系统，系统前端使用 Vue 3 + Element Plus 组件库构建用户交互界面，后端基于 Spring Boot 提供 RESTful 接口，前后端通过 axios 进行数据交互，实现完整的商品浏览、在线下单、支付充值与后台管理等功能。

## 功能特点

- ① 系统采用前后端分离架构，基于 MyBatis ORM 框架实现数据持久化，使用 MySQL 存储商品、订单、用户等核心数据，配合 PageHelper 实现列表分页查询，前端通过 Vue Router 管理页面路由，实现清晰的模块化页面组织。
- ② 系统提供完整的商城购物流程，包含商品分类浏览、关键词搜索、商品详情、购物车管理、一键下单、订单状态流转（待接单 → 已出货/已配送 → 已完成）以及取消订单自动退款等业务逻辑，同时支持余额充值与账户余额校验。
- ③ 基于 localStorage + 会话登录实现用户会话保持与登录状态管理，区分普通用户与管理端两种角色，通过统一 Result 封装接口返回，配合全局异常处理器实现统一的错误提示与权限控制。
- ④ 系统内置数据统计分析模块，基于 ECharts 实现近一周销售趋势折线图与分类商品销售额占比饼图，后台首页展示销售总额、今日销售额、商品总数、注册用户数等核心运营指标，为管理员提供数据决策支持。
- ⑤ 后台管理端提供完善的运营管理功能，包含商品、分类、轮播图、订单、用户、管理员、评论、收藏、充值记录、配送员等十大模块的增删改查管理，配送员信息支持后台动态维护，订单配送弹窗可快速选择预设配送员。

## 核心技术栈

Spring Boot + MyBatis + MySQL + Vue 3 + Element Plus + Vite + PageHelper + axios + vue-router + wangEditor + ECharts + Hutool
